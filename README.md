# Email Application

A **Spring Boot Email Application** that allows sending emails using Jakarta Mail. Built with Java 21, Spring Boot 3, and Lombok for cleaner code. Includes JUnit 5 for testing.

## Features

- Send emails using SMTP
- Simple configuration in `application.yml` or `application.properties`
- Clean and concise code with Lombok
- Unit tests with JUnit 5

## Technologies Used

- Java 21
- Spring Boot 3
- Jakarta Mail (spring-boot-starter-mail)
- Lombok
- JUnit 5
